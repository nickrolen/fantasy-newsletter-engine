# InfoTip

A small ⓘ beside any new or non-obvious number (OVR, POT, grades, lines, win %) that opens a one- or two-line plain explanation on tap.

- **Provide:** a short title and one or two sentences, written once per concept and reused everywhere that concept appears. The explanation says what the number means and how to read it, not how it is computed in detail.
- 16 px icon in `ink-3` inside a 44 px tap target. The popover is `dark` with `ink-on-dark` text, 240 px wide, closed by a second tap, a tap outside, or Escape.
- Tap, never hover: nothing in the hub is hover-only.
- Use it once per section, next to the section title or the column header, not on every row.
