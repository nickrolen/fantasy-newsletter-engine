# IssueBar

A slim white bar under the Home header that opens the latest newsletter issue, showing its headline.

- **Provide:** the week number, the issue's headline (from the drafting workflow), and the issue's link.
- One line; the headline truncates with an ellipsis, never wraps.
- Only on Home. The archive lives in League.
- Before the first issue with a headline exists, show "Week N issue" with no quote marks.
