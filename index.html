Fantasy Basketball Newsletter Engine

A weekly, sportsbook-style newsletter generated from a Yahoo Fantasy league.

Every issue below was produced by a six-stage data pipeline: Yahoo API to a 20+ module stats engine to tens of thousands of Monte Carlo simulations to a deterministic formatter that pre-cites every number, so the prose layer never invents a statistic. Each file is a single self-contained HTML page with inline CSS, JS, and data.
